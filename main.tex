\section{项目经历}
\entrytitle{基于大模型智能体的网络故障根因定位系统}{2025/12 -- 2026/03}
\tech{Python｜PEFT｜LoRA｜GRPO｜LangChain｜ReAct｜RAG}
\summaryline{面向真实网络运维中的故障定位需求，构建基于大模型智能体的网络故障根因定位系统，将结构化指标分析、知识检索增强与多步推理结合，实现从网络侧/用户侧观测信息到候选根因判别的自动化诊断。}
\begin{itemize}
  \item 基于网络故障数据集 TeleLogs 开展任务建模，围绕网络侧工程参数、用户侧观测指标、症状描述与候选根因集合，设计面向网络故障诊断的 \metric{SFT 数据构建流程}，构建 2,400 条监督微调样本。
  \item 提出\metric{两阶段蒸馏式 SFT 数据构建方法}：第一阶段采用排除法、矛盾法、规则法、统计法四类专家策略生成候选推理轨迹；第二阶段通过教师模型对正确轨迹进行整合、压缩与标准化重写，形成更适合模型学习的高质量 RCA 样本。
  \item 基于 \metric{Qwen2.5-7B-Instruct}，使用 \metric{PEFT} 实现 \metric{LoRA} 完成参数高效监督微调，并进一步结合 \metric{GRPO} 优化最终根因判别能力，提升模型在复杂故障场景下的输出稳定性与决策准确率。
  \item 基于 \metric{LangChain} 设计并实现融合 \metric{ReAct} 推理范式的智能体框架，封装表格解析、故障区间识别、服务小区几何分析、邻区干扰分析等工具模块，将原始网络数据转化为可供模型推理的结构化诊断证据；并构建规则化知识库与 \metric{RAG 检索模块}，使模型能够结合结构化证据与领域规则进行多步诊断推理，提升系统在复杂网络故障场景下的可解释性与稳定性。
  \item 微调后模型相较基础模型，Pass@1 从 12.04\% 提升至 53.59\%，Pass@4 从 12.50\% 提升至 54.86\%；引入 Agent 框架后，系统性能进一步提升至 \metric{Pass@1 76.50\%、Pass@4 78.36\%}。
\end{itemize}

\entrytitle{基于 Qwen3-VL 的多模态领域适配与参数高效训练}{2025/10 -- 2026/01}
\tech{Python｜PyTorch｜Qwen3-VL｜Transformers｜PEFT｜QLoRA}
\summaryline{面向通用视觉语言模型在垂直视觉场景中识别精度不足的问题，基于 Qwen3-VL-4B 构建多模态遥感图像识别模型，通过领域监督微调，使模型能够根据卫星图像识别水域、农田和城市建筑等多种土地覆盖类型。}
\begin{itemize}
  \item 基于公开的 BigEarthNet-S2 数据集构建\metric{多模态 SFT 数据}，从 Sentinel-2 卫星图像中提取 RGB 波段，按照类别均衡策略筛选 10,000 条训练样本和 1,000 条测试样本；将遥感图像、任务指令和多标签答案转换为 Qwen3-VL 对话格式，并统一标签名称、排列顺序及模型输出格式。
  \item 基于 \metric{Qwen3-VL-4B-Instruct} 进行 4-bit QLoRA 监督微调，采用 NF4 量化降低基础模型显存占用，在 Qwen3-VL 视觉与语言模块的线性层中注入 LoRA 适配器，冻结基础模型参数，并结合梯度检查点、梯度累积和 8-bit AdamW 完成参数高效训练；仅对 Assistant 输出计算训练损失，避免图像 Token 和用户指令参与监督。
  \item 设计多标签约束输出与结果解析模块，对模型生成标签进行去重、标准化及非法类别过滤，并使用 Micro-F1 和 Macro-F1 评估微调效果。
  \item 微调后模型相较原始 Qwen3-VL-4B，\metric{Micro-F1 由 0.274 提升至 0.629，Macro-F1 由 0.203 提升至 0.598}，验证了 4-bit QLoRA 对视觉语言模型进行领域适配的有效性。
\end{itemize}

\begin{itemize}
  \item 设计“需求解析—代码生成—模型构建—三视图渲染—视觉评估—迭代修复”的智能建模流程，基于 \metric{LangChain} 组织 Agent 的多步推理与工具调用，使系统能够围绕用户需求持续优化生成结果。
  \item 基于 \metric{Claude Sonnet} 对文本描述与输入图像进行联合理解，提取目标模型的几何特征、结构关系与建模约束，并据此生成 CadQuery / PythonOCC 参数化建模代码。
  \item 在 sandbox 中执行生成的 CadQuery / PythonOCC 参数化建模代码，完成 \metric{3D 模型构建与标准三视图渲染}，并将渲染结果反馈给 Agent 进行视觉一致性评估。
  \item 构建基于\metric{视觉反馈}的迭代修复机制：若当前模型与原始需求存在偏差，则重新生成或修正 CAD 代码并进入下一轮闭环；若满足一致性要求，则输出最终模型。
